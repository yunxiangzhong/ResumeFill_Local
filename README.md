# ResumeFill Local

ResumeFill Local 是一个本地优先的中文网申简历填写助手，适用于 Chrome 和 Edge。它基于 [OpenJobAutofill](https://github.com/Br1an67/OpenJobAutofill) 的页面扫描、字段识别和表单填写能力改造，重点支持飞书招聘、Moka、北森等常见招聘系统。

## 一眼看懂

| 对比项 | ResumeFill Local | 市面付费工具（常见情况） |
| --- | --- | --- |
| 是否收费 | 免费、开源 | 常见订阅、按次收费，高级功能可能另计 |
| 是否联网 | 填写和匹配逻辑可离线运行，不请求远程 API | 通常需要联网，具体取决于产品和功能 |
| 是否有次数限制 | 没有服务端次数或额度限制 | 可能有套餐、次数或额度限制 |
| 数据存哪 | 保存在当前浏览器的 `chrome.storage.local`，留在本机 | 可能上传云端或由服务商托管，需查看具体隐私政策 |

市面工具的实现方式各不相同，付费前请以对应产品的隐私政策和服务条款为准。

## 隐私边界

- 简历资料只保存到当前浏览器的 `chrome.storage.local`。
- 插件没有账号、云同步、云端 AI、统计上报和自动更新检查功能。
- Manifest 只申请 `activeTab`、`scripting`、`storage` 三项权限。
- 只有你点击插件并开始操作当前页面时，才会注入页面脚本。
- 字段匹配使用本地规则；不会把简历值发送给任何 AI 或插件服务器。
- 不读取或自动选择本地附件，不填写密码、验证码和文件上传框。
- 不自动点击保存、下一步、投递或最终提交按钮。

填写到招聘网站后，网站本身可能读取或自动保存字段内容。因此，填写前请在设置页逐项核对资料，填写后再检查页面上的证件、联系方式、日期、选择题和声明类问题。

## 功能

- 多份简历：新建、切换、重命名、删除。
- 资料模块：基本信息、求职意向、教育、实习/工作、项目、校园经历、奖项、语言、证书、论文、专利、自我介绍及自定义字段。
- GPA/绩点字段不参与自动匹配或填写；需要填写时由你在招聘网站上手动处理。
- JSON 备份：一次导出全部简历；导入前显示数量并确认替换，未内置字段和自定义模块也会保留。
- 本地表单识别：支持文本框、文本域、原生下拉、单选、多选、日期和常见 React/Vue/Ant Design/Element UI 控件。
- 手动复核：对低置信度、已有内容或特殊控件，页面会标为橙色，由你在招聘网站上确认。
- 结果标记：绿色表示已填写，橙色表示待处理或需要复核。

## 安装

1. 下载或克隆本项目。
2. 打开 `edge://extensions/` 或 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的项目目录。
6. 点击扩展图标，打开“设置”维护本机简历资料。

运行扩展不需要安装 Node.js 或构建依赖，直接加载项目目录即可使用。开发者如需运行本地回归测试，请使用 Node.js 20 或更高版本，并在项目目录执行：

```bash
npm ci
npm run test:install
npm test
```

测试只使用本地虚构页面和 Playwright Chromium。Linux 如果缺少系统依赖，请改用 `npx playwright install --with-deps chromium`。

## 使用

1. 在设置页新建或选择一份简历，填写资料后点击“保存资料”。
2. 打开招聘网站的简历编辑页或申请表单页。
3. 点击插件图标，选择“开始填写”。
4. 查看页面上的绿色和橙色标记；待处理字段由你在招聘网站上确认或填写。
5. 人工核对完整内容后，由你自己决定是否点击招聘网站的提交按钮。

每进入一个新步骤或页面，都要重新点击“开始填写”。插件不会自动跨页继续填写。

## 备份与迁移

设置页的“导出资料备份”会导出全部本地简历。导出的 JSON 未加密，请只保存到你信任的位置。导入会替换当前浏览器中的简历库，操作前会再次确认。

## 目录

```text
manifest.json       # Manifest V3 权限与入口
src/background.js   # 本地简历库与扩展消息接口
src/options.*       # 多份简历资料编辑、导入和导出
src/popup.*         # 当前页面操作入口
src/content.js      # 页面扫描、本地匹配和填写执行
sample-profile.json # 虚构示例资料
```

## 已知限制

- 招聘系统的自定义下拉、日期面板和动态表单差异很大，无法识别时会标为待处理。
- 站点适配器依赖公开 DOM 结构，网站改版后需要重新核对。
- 浏览器扩展存储属于本机浏览器资料，不等同于操作系统级加密；请做好备份和设备访问控制。
